# yanGameEngine
Yet Another Nameless Game Engine with no actual goal.

# Prerequisites
## Linux
1. gcc, make, libxkbcommon
2. vulkan-sdk for debug build
## Windows
1. gcc, make
2. vulkan-sdk for debug build

# Building & Running
```
$ make
$ make run
```
